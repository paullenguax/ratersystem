# Feedback  *(senior rater / admin)*

Builds a written ICAO feedback report for **a candidate** from standard
wording, so reports are consistent between raters.

> This page writes feedback to **test candidates**. Feedback emails to
> **raters** on a course are written on **Reports** instead (admin only).

## How to use it

1. **Choose the candidate.** Use one of the two buttons at the top:
   - **From test bank**: pick the recording from the list. The candidate's
     name and test number fill in.
   - **Manual entry**: type the **Candidate name** and, if you have one,
     the **Test number**.
2. **Score each area.** The six tabs (PRO, STR, VOC, FLU, COM, INT) are the
   ICAO areas. Pick a tab, then click a level from **1 to 6**. A tab shows
   **✓** once it has a score.
3. **Edit the wording.** Each level comes with a standard paragraph, which
   appears in **Feedback text**. Change it as needed for this candidate.
   - **↺ Reset to placeholder** throws your edits away and brings back the
     standard paragraph.
   - Picking a **different level** for an area also replaces your edits
     with that level's standard paragraph.
4. **Copy the report.** The **Compiled report** on the right shows the
   header ("Name — Test 23"), then each scored area in order. The counter
   shows how many areas are done, e.g. **(4/6)**. Click **Copy** and paste
   it wherever the report is issued.

## Good to know

- Nothing is saved. If you switch candidate or leave the page, the report
  is cleared, so copy it first.
- The standard paragraphs are shared. Editing them for one report doesn't
  change them for the next one.
