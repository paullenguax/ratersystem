# Feedback Reports

Builds a written feedback report for a candidate from standard wording, so
reports are consistent between raters.

## How to use it

1. Pick a test from Test Bank, or enter the candidate's details by hand.
2. Enter a score for each of the six ICAO areas.
3. The report panel fills in with the standard paragraph for each score.
   Edit the text as needed for this candidate.
4. **Copy to clipboard** and paste it wherever the report is issued.

## Good to know

The starter paragraphs are a shared set of texts. Changing them for one
report doesn't change the template for the next one.
