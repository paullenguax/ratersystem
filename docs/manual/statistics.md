# Statistics  *(admin)*

Rater‑reliability analysis for a course — how consistently each rater marks,
and how they compare to the group.

## How to use it

1. Run the marking and publish it.
2. Feed the published scores through the Rasch analysis
   (**Admin → Import Rasch Results**, pasting a Facets `.out` file).
3. This page then shows rater measures and the Wright map.

## Good to know

The analysis is only as current as the last `.out` file you imported. There
is no automatic recalculation.
