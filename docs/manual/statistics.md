# Statistics  *(admin)*

This page shows how raters, tests and the scale behave across the whole
system. The Rasch analysis here runs live in your browser each time you open
a tab, so there's nothing to import.

> Writing a rater's feedback email? That's done on **Reports**, which has
> its own step-by-step guide. You don't need to visit this page for it.

## Using it

Use the **Session** box at the top to choose what's analysed:
**All sessions** means published scores only. Picking an event adds that
event's unpublished scores.

| Tab | What it's for |
|---|---|
| **Overview** | Spread of overall levels, average per criterion, and how far raters agree on recordings that several people scored. |
| **Raters** | Every rater's strictness (target ±1), Infit/Outfit (target 0.7–1.3) and discrimination. Hover a column heading for an explanation. |
| **Tests** | Each recording's calibrated level, how hard it is to rate, and how much raters disagree on it. You save the calibration from here. |
| **Scale & criteria** | How hard each criterion is to score highly on, and whether the six levels are used in order. |
| **Returning raters** | Compares a rater's strictness across each event they've taken part in. |
| **Anchors** | Sets up a fixed baseline so that the whole rater population drifting over time becomes visible. Follow the numbered steps on the tab. |
| **Standardization** | The same analysis for examiners' standardization scores. |

## Good to know

Rows from raters without a permanent number are skipped. If a tab mentions
this, click **Assign numbers** on the **Scores** page.
