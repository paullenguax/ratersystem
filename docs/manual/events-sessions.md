# Events (Sessions)  *(admin)*

A "session" is a named batch of marking work — for example
*"June 2026 Refresher Course"*. Assignments hang off a session.

## How to use it

1. Create a session, give it a name and a type (rater course, refresher,
   reliability, calibration, examiner standardization, ad hoc, …).
2. Build assignments against it (see **Assignments**).

The session type is just an organisational label — it does **not** restrict
which kind of assignment (rater‑course or standardization) the session can
hold.

## Good to know

Self‑serve exam entries create their own session automatically, named after
the Canvas course and section, so you may see sessions you didn't make by
hand.
