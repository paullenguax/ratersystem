# Events (Sessions)  *(admin)*

An **event** (called a "session" in older parts of the system) is a named
batch of marking work, for example *"June 2026 Refresher Course"*.
Assignments belong to an event, and **Reports** and **Statistics** let you
pick one.

## Creating an event

Click **New session** and fill in:

- **Name**: what everyone will see in dropdowns. Make it clear which course
  and cohort it is.
- **Type**: Rater Course, Refresher Course, Reliability Check, Calibration,
  Examiner Standardization, Ad hoc, or Historical Import. This is only a
  label for organising. It doesn't restrict which kind of assignment
  (Certification or Standardization) the event can hold. Once any scores have
  been submitted for the event, the type is **locked**.
- **Status**:
  - **Open**: the event is in use. Only open events appear when you create
    assignments or use Quick entry.
  - **Closed**: the event is finished and no longer offered for new
    assignments.
  - **Published**: the event is fully published.
- **Notes**: optional.

**Edit** on a row changes any of these later.

## Good to know

- Self-serve exam entries create their own event automatically, named
  *"Canvas course — section"*, so you may see events you didn't make by
  hand.
- An event's status is set by hand. Publishing assignments doesn't change
  it, so close events yourself when they're finished.
