# Benchmark Check  *(admin)*

Admin screen for the ICAO screener test that lives at
`lenguax.com/benchmark/`. Two tabs.

## Results

Every completed Benchmark attempt: candidate name and email, timestamp,
per‑item answers (expand a row), the three phase scores, and an indicative
level (below 4 / 4 / 5 / 6). You can link a result to a known person, and
delete results. Export to CSV.

## Items

The question bank for the test: create/edit multiple‑choice items, set the
pool/section/band, mark items active or inactive, and seed a starter set.

## Good to know

The Benchmark test runs against a **separate Firebase project**. This page
bridges your admin identity across on every load, so if a query briefly
fails right after opening, give it a second and refresh.
