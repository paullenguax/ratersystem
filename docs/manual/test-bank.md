# Test Bank  *(admin)*

Every candidate recording the system knows about, with its metadata.

## What's in a test record

- Test number, candidate name, test type
- The audio recording
- **Category**: `rater_course` or `standardization` — this decides which
  pool the test belongs to and keeps the two pipelines separate. A
  standardization test gets an **S‑number** (S1, S2…) automatically.
- Optional **course tag** (rater course / refresher / other) and
  **day label** to help find the right recording when building a Practice
  Session.
- Optional **duration**.

## Adding a test

Use **Add test**, fill in the fields, upload the audio. The system blocks a
duplicate test number within the same category.

## Good to know

- Older imported tests (roughly the first 50) have a plain numeric ID from
  the original spreadsheet import; newer non‑standardization tests may have
  no number unless you type one in.
- The Storyline / TEAC speaking‑test audio is **not** here — that has its
  own content system under **Test Versions**.
