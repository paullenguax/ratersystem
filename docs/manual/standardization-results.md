# Standardization Results  *(admin)*

Every score from the **Standardization** pipeline, live as soon as it's
saved. There's nothing to publish.

## Using it

- **Search** by rater, candidate or event.
- Click a column heading to sort by it. Hover a heading (PRO, STR…) to see
  the full criterion name.
- **▶** plays that recording above the table, so you can listen while you
  compare scores.
- The comments column shows each person's comment. Hover it to read a long
  one in full.
- **Export CSV** downloads whatever the search is currently showing.

## Good to know

- To see everyone's scores for one test side by side, open the assignment
  under **Assignments → View**.
- To see how examiners compare statistically, go to the
  **Statistics → Standardization** tab. It needs at least 2 examiners
  scoring at least 2 tests.
