# Standardization

A separate marking pipeline used for standardization exercises — getting a
group of raters or examiners to score the same recordings and comparing how
close they are. It is completely separate from the real rater‑course
marking in **Scoring**: different tests, different results, no
cross‑contamination.

## How it works

1. An admin assigns one or more standardization tests to you.
2. Open the **Standardization** tab and score each test the same way as in
   Scoring — six ICAO areas, 1–6 — plus a short **comment** (up to ~250
   characters) per test.
3. Draft scores save automatically. There's a review‑then‑confirm step, the
   same as Scoring.

## Differences from Scoring

- **No publish step.** Scores are visible in Standardization Results as soon
  as they're saved.
- **No anonymisation.**
- The same test can be given to several people so their scores can be
  compared side by side (admins do that comparison on the Assignments
  review page).
