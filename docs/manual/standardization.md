# Standardization

Standardization is a separate marking pipeline for standardization
exercises: getting a group of raters or examiners to score the same
recordings and comparing how close they are. It's completely separate from
the real rater-course marking in **Scoring**. It uses different tests and
keeps different results, so nothing mixes.

You see this tab if you're an examiner or an admin, or if an admin has
ticked **Can do standardization work** on your People record.

## How it works

1. An admin assigns you one or more standardization tests.
2. Open **Standardization** and score each test the same way as in
   **Scoring**: six ICAO areas, 1–6, with the same slider, number box and
   1–6 keyboard shortcut.
3. Optionally add **Comments** for each test. The counter shows how much of
   the 250-character limit you've used.
4. Saving and moving between tests works as it does in Scoring. When
   everything is scored, check the summary and click **Yes, that's my
   scores**. The admin is emailed when you confirm.

## Differences from Scoring

- **No publish step.** Admins see the scores in **Standardization Results**
  as soon as they're saved.
- **No anonymisation.** You see the candidate's name.
- The same test is often given to several people so their scores can be
  compared side by side. Admins do that on the **Assignments** review page
  and on the **Statistics → Standardization** tab.
