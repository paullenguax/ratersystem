# Rater Admin System: overview

This is the tool the aviation-English rater team uses to run rater
training courses, mark speaking tests, issue certificates, and manage the
TEAC speaking-test content. What you see in the sidebar depends on your
role.

## Roles

| Role | Sidebar tabs |
|---|---|
| **Trainee** | Dashboard, Scoring, Sample Collection, User Manual |
| **Senior rater** | The trainee tabs, plus **Feedback** |
| **Examiner** | Dashboard, Standardization, User Manual |
| **Admin** | Everything |

Two ticks on a person's **People** record add tabs on top of their role:

- **Can do standardization work** adds the **Standardization** tab to a
  trainee or senior rater.
- **Trainer** adds the **Courses** tab. Admins always have it.

This manual only lists the sections you can open.

## Signing in

- **Trainees and most raters**: click **Log in with Canvas** on the login
  page. It uses the same login as the course itself. You need a People
  record first, which an admin creates with **Canvas Sync**.
- **Trainees taking their end-of-course exam**: use the self-serve link
  (`/take-test`) from the course. **Continue with Canvas** signs you in
  and gives you 4 tests to score straight away.
- **Admins and invited users**: sign in with email and password. If you've
  forgotten your password, type your email in, then click **Forgot
  password?** to get a reset link.

## How a rater course runs, start to finish

The usual sequence for admins, with the section of this manual that covers
each step:

1. **Before the course**: run **Canvas Sync** so every attendee gets a
   People record (**Admin tools**), and record the course run and who's
   attending (**Courses**).
2. **During the course**: play Training audio and collect the room's
   scores live (**Practice Sessions**).
3. **The exam**: each trainee scores 4 Certification recordings. They
   either use the self-serve link, which needs no setup, or you build their
   sets yourself (**Assignments**, **Auto-assign**).
4. **Trainee confirms**: the trainee clicks **Yes, that's my scores** on
   their own screen (**Scoring**), and you get an email.
5. **Feedback**: run the Rasch analysis, write the feedback email and issue
   the certificate (**Reports**).
6. **Publish**: publish the assignment so its scores join the main pool
   (**Assignments**). Then assign permanent rater numbers (**Scores**).

## Words used throughout

- **Event** (sometimes called a **session**): a named batch of marking
  work, such as one course cohort.
- **Assignment**: one rater, one event, and a set of tests to score.
- **Test**: one candidate recording in the **Test Bank**.
- **Certification / In-session / Training**: the three pools a recording
  can belong to. Only Certification recordings are used in exams. See
  **Test Bank**.
- **Publish**: makes an assignment's scores official, so they count
  towards everyone's statistics.
- **Rasch analysis**: the statistical model that measures how strict and
  how consistent each rater is. See **Reports** and **Statistics**.

## Getting help
