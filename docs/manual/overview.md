# Rater Admin System — overview

This is the tool the aviation‑English rater team uses to run rater training
courses, mark speaking tests, issue certificates, and manage the TEAC
speaking‑test content. What you see in the sidebar depends on your role.

## Roles

| Role | Typically can see |
|---|---|
| **Trainee** | Dashboard, Scoring, Standardization, Sample Collection, User Manual |
| **Senior rater** | The above plus Feedback Reports |
| **Examiner** | Dashboard, Standardization, User Manual |
| **Admin** | Everything |

Some pages open up for a senior rater or trainee only if an admin has ticked
**Can standardize** on their People record.

## Signing in

Most people sign in with their Canvas account ("Continue with Canvas" on the
login page) — the same login used for the course itself. A few admin
accounts use email + password; "Forgot password?" on the login screen sends
a reset link.

## Getting help

Each section of this manual matches a sidebar tab. If something here is out
of date or unclear, tell the system admin — the manual lives alongside the
code and is meant to be corrected quickly.
