# Courses  *(trainers)*

A record of every Initial Rater Course and Refresher Course run: **who
attended** and **which audio was played**. Anyone on a course counts as
having heard all of its audio. That lets you pick recordings a new group
hasn't heard before.

You see this tab if you're an admin, or if **Trainer** is ticked on your
People record.

## The course list

- **+ Rater course** / **+ Refresher course** create a new run. Fill in:
  - the **Name**
  - the **Start date** and **End date**
  - the **Trainers**: anyone with the Trainer tick
  - **Notes**, if needed
  - for refreshers, the **Refresher set** (RC number) this run delivers.
    The newest set is suggested.
- **Materials & documents**: files and notes shown on every course of a
  type, plus general documents (see *Materials* below).
- **Import past courses**: bulk-add old courses from a spreadsheet (see
  below).
- **Re-sync from sets** copies a set's current recordings (the Rater Course
  set, or an RC set) into its courses. Use it as you tag recordings in Test
  Bank: tag Day 1, re-sync, tag Day 2, re-sync again. Courses where a
  trainer added or removed audio by hand are skipped and listed. Once a set
  is settled, fill in **Only courses starting on or after** so a later
  change only reaches current and future cohorts, and past courses keep the
  audio they actually heard. If any courses have no audio yet, a banner
  opens this panel.

Click a course to open it. **Edit** on the course page changes its details
or deletes it.

## Attendees

- **Link a Canvas section…** pulls in every student from that section and
  matches them to People records. Each linked section then has its own
  button for pulling it again, which picks up late enrolments. Sections
  that ended more than a week ago aren't listed, so add those attendees by
  hand.
- **Add a person by name or email**: pick from People, or type a name for
  someone who has no People record. They're tracked by name only and
  marked as such.
- **✕** removes an attendee.

## Audio

- Every course starts with its **set**: the Rater Course set (Training
  recordings tagged with a day in **Test Bank**, grouped by day here) or
  its RC set (recordings tagged with that RC number). **Update from set**
  copies the current set in again, replacing any changes made for this
  course.
- **Add audio** adds a recording for this course only. Search the Training
  pool; two filters are on by default:
  - **New to everyone on this course** hides anything an attendee has
    already heard on another course, so add the attendees first.
  - **Hide audio already in a course set** hides recordings that belong to
    a set, since those have been heard by everyone who took that course.

  A **heard by N** label shows how many attendees have heard a recording.
  Hover it to see who. **Done adding** closes the picker.
- **▶** plays a recording, and **✕** removes it from the course.

## Materials

Each course page has a **Materials** section. It shows files and notes for
that run, plus the shared ones for its course type.

- **Upload files** for PDFs, slides and so on.
- **New note** opens a written note (Markdown) with a live preview.
  **Ctrl+S** saves. **Print / PDF** prints the note, and **.md** downloads
  it.
- The icons on an item rename or delete it.

Use **Shared materials** on the course list for anything that applies to
every rater course or every refresher course.

## Importing past courses

1. Paste from a spreadsheet, including the header row, or upload a CSV.
   Use one row per attendee per course. Only the **name** and **course
   type** are required (e.g. "Initial", "Refresher 3" or "RC3"). Dates are
   optional and can be in most common formats. Click **Read**.
2. Under **Columns**, check that each column has been recognised correctly,
   and change it if not.
3. Check the preview. Rows are grouped into courses. **Adds to existing
   course** means the rows will join a course that's already recorded
   instead of creating a duplicate.
4. For each person, check who they've been matched to. A **Maybe:**
   suggestion is never linked unless you choose it. **Name only (not in
   People)** keeps them as a name.
5. Run the import. Running it again is safe: people already on a course
   aren't added twice. **Start again** clears the page.

## Good to know

- Who has heard what is also shown elsewhere: **Heard on courses** on a
  Training test in **Test Bank**, and **Courses attended** on a person in
  **People**.
- Course audio always comes from the **Training** pool. It can never end
  up in an exam.
