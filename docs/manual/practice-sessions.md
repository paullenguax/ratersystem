# Practice Sessions  *(admin)*

Live scoring practice during a course. The trainer plays a recording to the
room, participants score it on their own devices, and the trainer sees
everyone's scores come in.

Open it from **Admin → Practice Sessions**.

## Running one

1. Click **New session**. Give it a **Session title** (e.g. "Module 3 –
   Pronunciation focus") and optionally pick a **Test recording**.
   - Only **Training** audio is offered. You can filter it by Rater Course
     day. Certification recordings must stay unheard until the exam, so
     they never appear here.
   - If you choose **— Trainer plays audio externally —**, you play the
     audio from somewhere else, such as a file on your computer.
2. Click **Copy link** and share it (`/practice/<code>`). Participants
   sign in with Canvas, or type their name if they can't. Either way, you
   see their name next to their scores.
3. **Play the audio** from the trainer screen, e.g. over the room's
   speakers. The speed buttons (0.75×–1.5×) change the playback speed.
   Participants don't get their own player. They only enter scores.
4. **Watch the results** fill in live (a **Live** badge shows while the
   session is open).

## The buttons

| Button | What it does |
|---|---|
| **Hide names / Show names** | Hides names and shuffles the rows, so you can show the screen to the class and discuss the spread anonymously. |
| **Export CSV** | Downloads the scores. |
| **Clear scores** | Deletes every score in this session (you're asked to confirm), so you can reuse it for another round. |
| **Save N to standardization pool** | Copies the scores from Canvas-signed-in participants into the Standardization results. It's only available when the session uses a recording from the bank and has scores that haven't already been saved. |
| **Close session** | Ends the session. Participants then see "This session is closed". |

In the session list, use the copy icon to copy a session's link again, or
the bin icon to delete the session and all its scores.

## Good to know

Scores from someone who typed a name instead of signing in with Canvas can
never be saved to the standardization pool. This is deliberate, because
there's no confirmed person to attach them to.
